PROJETO TCC: CARTAS ELEMENTAIS

AUTOR: Lucca & Antonio

============================================================

RESUMO DO SISTEMA
Jogo de estratégia de cartas baseado em turnos para 2 jogadores (ou contra BOT).

MODOS DE JOGO (dois)
Primeiro - vida elementar
Objetivo: zerar a vida do adversário com base no dano do valor das cartas por turno

Segundo - mão cheia
Obejtivo: chegar a uma quantidade de cartas em mão

MECÂNICA DE JOGO (GAMEPLAY)
Início: Cada jogador começa com 3 cartas.

Turno:

1.Cada carta deve começar com um valor aleatório de 1 a 10

Jogadores escolhem uma carta (em segredo).

Jogadores escolhem a ação: ATAQUE ou DEFESA.

Revelação: As cartas e valores são mostrados.

Resolução: O vencedor da rodada pega todas as cartas jogadas.

REGRAS DE COMBATE E "MISTURA"

A "Mistura" é o cálculo final baseado na Tabela Elementar:

[MATRIZ DE AÇÕES]

ATAQUE vs ATAQUE: Ambos aplicam bônus elementais (2x ou 4x).

ATAQUE vs DEFESA: A defesa anula a mistura. Compara-se apenas o valor bruto.

DEFESA vs DEFESA: Rodada passiva. As cartas voltam para o baralho.

[REGRA DE DESEMPATE]

1º Empate: Nova rodada acumulando as cartas anteriores.

2º Empate: Disputa pura no dado (quem tirar maior valor ganha).

TABELA ELEMENTAR (MODIFICADORES) (ORDEM ALFABÉTICA)
Aço: 2x Gelo, Pedra, Fada / 0.5x Fogo, Água, Elétrico, Aço.

Água: 2x Fogo, Terra, Pedra / 0.5x Água, Grama, Dragão.

Dragão: 2x Dragão / 0.5x Aço / 0x Fada.

Elétrico: 2x Água, Voador / 0.5x Elétrico, Grama, Dragão / 0x Terra.

Escuridão: 2x Psíquico, Fantasma / 0.5x Lutador, Escuridão, Fada.

Fada: 2x Lutador, Dragão, Escuridão / 0.5x Fogo, Veneno, Aço.

Fantasma: 2x Psíquico, Fantasma / 0.5x Escuridão / 0x Normal.

Fogo: 2x Grama, Gelo, Inseto, Aço / 0.5x Fogo, Água, Pedra, Dragão.

Gelo: 2x Grama, Terra, Voador, Dragão / 0.5x Fogo, Água, Gelo, Aço.

Grama: 2x Água, Terra, Pedra / 0.5x Fogo, Grama, Veneno, Voador, Inseto, Dragão, Aço.

Inseto: 2x Grama, Psíquico, Escuridão / 0.5x Fogo, Lutador, Veneno, Voador, Fantasma, Aço, Fada.

Lutador: 2x Normal, Gelo, Pedra, Escuridão, Aço / 0.5x Veneno, Voador, Psíquico, Inseto, Fada / 0x Fantasma.

Normal: 0.5x Pedra, Aço / 0x em Fantasma.

Pedra: 2x Fogo, Gelo, Voador, Inseto / 0.5x Lutador, Terra, Aço.

Psíquico: 2x Lutador, Veneno / 0.5x Psíquico, Aço / 0x Escuridão.

Terra: 2x Fogo, Elétrico, Veneno, Pedra, Aço / 0.5x Grama, Inseto / Causa 0x Voador.

Veneno: 2x Grama, Fada / 0.5x Veneno, Terra, Pedra, Fantasma / 0x Aço.

Voador: 2x Grama, Lutador, Inseto / 0.5x Elétrico, Pedra, Aço.
